# Hardware Specifications & Layout

## Bill of Materials (BOM)
- **Controller:** ESP32 DevKit V1 (30-pin or 38-pin, dual-core Xtensa @ 240 MHz)
- **Clock Display:** 84-pixel circular addressable RGB LED ring (WS2812B)
- **Audio Output:** MAX98357A mono I2S amplifier breakout or PCM5102A stereo DAC
- **Acoustic Transducer:** 3W / 4Ω or 5W / 8Ω speaker enclosure
- **Timekeeper:** DS1307 real-time clock module with 32.768 kHz crystal and CR2032 battery
- **Power:** 5V 2.5A regulated switching power adapter
